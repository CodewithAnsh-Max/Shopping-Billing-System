# Shopping Billing System (Python)

Ye ek console-based Shopping Billing System hai jo Python me bana hai.

## Features

* Customer details input
* Multiple products add kar sakte ho
* Automatic bill calculation
* Discount support
* 18% GST calculation
* Bill text file me save hota hai

## Run kaise kare

```bash
python bill.py
```

## Technologies

* Python
* File Handling
* Loops
* Conditional Statements
* Functions
